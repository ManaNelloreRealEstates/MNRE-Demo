# ManaNelloreRealEstate

Working UI prototype for a Nellore property platform. Listings, people and deals are sample data stored in the browser. There is no live backend.

## Run

```bash
npm start
```

Open `http://localhost:4200`.

## Demo login

Password for every account: `12345678`

| Actor | Email |
| --- | --- |
| Buyer | buyer@mananellore.com |
| Owner | owner@mananellore.com |
| Associate | associate@mananellore.com |
| Builder | builder@mananellore.com |
| Admin | admin@mananellore.com |

The login page can sign you in as any of these actors. Use **Reset demo data** on the login page or in Admin → Settings to restore the original sample records.

## Flow to try

1. Search plots, houses, or both from the homepage.
2. Open a property as the buyer and choose **I'm interested**, then schedule a site visit.
3. Sign in as admin and find that lead, confirm the visit, and open a deal.
4. Sign in as the owner, associate and builder to see the same records from each desk.
